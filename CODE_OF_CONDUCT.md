# Code of Conduct

Brieflow adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. It applies in the repository, its issues, pull requests and Discussions, and wherever someone represents the project.

We want Brieflow to be a welcoming place for everyone, whatever their background or experience. Be respectful, give and accept constructive feedback, and focus on what is best for the community. Harassment and personal attacks are not acceptable.

## Reporting

Report unacceptable behavior to the maintainers at matteo.dibernardo@gmail.com. All reports are reviewed promptly and kept confidential. The maintainers enforce the code of conduct as the Contributor Covenant's enforcement guidelines describe.
