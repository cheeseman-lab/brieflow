# Security

## Reporting a vulnerability

Do not report security problems in public issues or Discussions. Use GitHub's [private vulnerability reporting](https://github.com/cheeseman-lab/brieflow/security/advisories/new), or email matteo.dibernardo@gmail.com.

Include what is affected, how to reproduce the problem, and the brieflow version. We reply within a week and keep you informed until a fix is released.

## Supported versions

Fixes go into the latest release on `main`.
